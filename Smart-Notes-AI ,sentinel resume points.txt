Smart-Notes-AI – Intelligent Study Asset Generator
Tech Stack: Python, Flask, SQLite, EasyOCR, PyMuPDF, Google Gemini API, ReportLab

Engineered a full-stack AI pipeline to transform multi-page handwritten notes and PDFs into structured digital assets using EasyOCR and PyMuPDF.

Implemented a multi-tenant architecture with Flask-Login and SQLite, enabling secure user sessions and personalized note storage.

Developed an interactive 3-column dashboard that provides AI-driven text cleaning, conceptual summarization, and dynamically generated practice quizzes.

Automated the generation of professionally formatted study guides using ReportLab, allowing users to export AI-processed content as offline PDF files.

Sentinel – Autonomous Agentic AI Security Auditor
Tech Stack: Python, LangGraph (Agentic AI), Docker, Network Security Protocols, Gemini 1.5 Pro

Developed an autonomous Agentic AI system using LangGraph to perform automated security audits and vulnerability assessments on web applications and source code.

Implemented a self-reasoning agent capable of simulating cyber-threats across the CIA Triad (Confidentiality, Integrity, Availability) to identify system weaknesses.

Designed a dynamic reporting engine that provides actionable mitigation strategies and security patches based on autonomous audit results.
